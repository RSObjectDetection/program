# 芯片 OK/NG 实验报告（S01–S09）

## 结论摘要

在当前“由同版六类 NG 图像取像素中值得到合成 OK”的封闭数据条件下，最佳工业候选是 **S08：ResNet-18 CPG-SSN + Top-2 聚合**。它在 20 张合成 OK、120 张真实 NG 的独立测试集上得到 0 FP、0 FN，同时只有 4.56M 参数，RTX 4090 上单个 256×256 图块平均推理 0.709 ms。

这些结果证明了方案和代码链路可行，但不能直接视为产线准确率。真实 OK 的照明、批次、曝光、污染和位置波动尚未进入验证/测试；上线前必须增加真实 OK 校准集并冻结阈值后再做盲测。

## 数据和评价协议

- 原始数据：693 张 NG 图、693 个 VOC XML；六类缺陷为 missing_hole、mouse_bite、open_circuit、short、spur、spurious_copper。
- 发现 115 个完整同版组；每组包含同一模板/样本序号的六类缺陷图，底图高度对齐。
- OK 生成：对同组六张 RGB 图逐像素、逐通道取中值。局部缺陷在不同类别/位置不一致，因此中值图保留共同正常结构并抑制异常区域。
- 常规切分：按同版组整体划分 80/15/20 个训练/验证/测试组，严禁近重复底图跨集合。
- 常规测试集：20 张合成 OK、120 张真实 NG，共 140 张。
- S07 曲线切分：100/5/10 个训练/验证/测试组；30、50、100-shot 使用嵌套训练子集，每个 shot 表示每类 NG 图像数。
- 训练时使用 XML 框中心选择含缺陷训练块；推理只输出整图 OK/NG，不输出框或掩码。
- 阈值只在验证集拟合，再原样应用到测试集。

## 统一训练设置

- 输入图块：原图 512×512 滑窗，网络输入缩放为 256×256。
- 默认重叠：128；S06 改为 64。
- 训练：12 epochs，每轮加权采样 2000 图块，batch 16，固定随机种子。
- 主干：S01–S07 为 WideResNet-50-2；S08 为 ResNet-18。
- S02：加入同模板、同坐标正常原型余弦残差。
- S03：加入 GLASS 风格梯度困难特征扰动。
- S04：同时加入上述两模块，称为 CPG-SSN。
- 整图分数：比较 Max、Top-2 均值、Top-3 均值；主表按预设 Top-2 报告。

## S05：聚合消融

S04 使用同一权重比较三种整图聚合：

| 聚合 | 验证 F1 | 测试 F1 | 测试 NG 召回 | 测试 OK 特异度 | FP/FN |
|---|---:|---:|---:|---:|---:|
| Max | 0.9944 | 0.9707 | 0.9667 | 0.8500 | 3/4 |
| Top-2 | 1.0000 | 0.9877 | 1.0000 | 0.8500 | 3/0 |
| Top-3 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 0/0 |

Max 对单个偶发高分图块最敏感。Top-2 与 Top-3 在验证集并列，测试表现只能用于诊断、不能反向选参。S08 上 Top-2 的校准表现优于 Top-3，因此最终候选保留 Top-2，真实 OK 到位后再重新比较。

## S09：阈值校准

以 S08 最佳权重进行校准：

- Top-2：F1 最优/零验证漏检阈值为 0.78639，零验证误报阈值为 0.78552；三种策略在测试集均为 0 FP、0 FN。
- Top-3：对应阈值约 0.777；测试集为 0 FP、1 FN，NG 召回 0.9917。
- 当前建议的临时阈值为 Top-2 的 0.78639，但它只对合成 OK 有效，不能直接部署。

## 消融分析与工业建议

1. 单独增加原型或困难扰动并不稳定。S02 的验证集完全分离，但 Top-2 阈值迁移到测试集后出现 4 个 OK 误报；S03 收敛更慢且没有超越基线。
2. 两模块组合主要改善“零漏检”倾向。S04 的 NG 召回为 1.0，但 Overlap=128 下产生 3 个 OK 误报；减小重叠到 64 后 S06 达到全对，同时测试图块数由 5166 降至 4056，整图计算量约降低 21%。
3. 30-shot 已能覆盖六类缺陷且未漏检，但阈值正常侧不稳；50-shot 是当前数据上的更合理起点。100-shot 未单调提升，主要原因是固定 2000 图块/epoch 令每张训练图的曝光次数降低，且只有 5 张 OK 用于曲线验证。已安排增加采样预算的补充实验。
4. ResNet-18 是当前最有价值的改动：参数量减少约 86.5%，单块推理快约 3.4 倍，并保持测试全对。部署候选无需 WideResNet-50-2。
5. 下一步应优先采集真实 OK，而不是继续堆模型：至少覆盖多个批次、班次、曝光和轻微位置变化；建议 100–300 张用于阈值校准，另留完全隔离的真实 OK/NG 盲测集。
6. 产线阈值应按漏检成本设定，并记录灰区。建议设置低阈值直接 NG、高阈值直接 OK、中间区间复检；当前数据不足以可靠估计该灰区。
