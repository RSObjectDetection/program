# CPG-SSN 严格无回放迭代训练报告

## 1. 结论

本轮 `H01–H06` 与 `V10–V100` 共 16 个阶段已全部完成。训练严格遵循以下约束：后续阶段继承上一阶段模型权重，但只使用本阶段新增 NG 图像；历史 NG 不进入当前阶段训练；训练 OK 始终固定为同一组 80 张合成图像。

- 横向最终阶段 H06：自适应阈值下 F1/NG 召回率/OK 特异度均为 **1.0000**，`TN=20, FP=0, FN=0, TP=120`。
- 横向 H06 使用 H01 固定阈值 0.69：F1 **0.9873**、NG 召回率 **0.9750**、OK 特异度 **1.0000**，`FP=0, FN=3`。
- 纵向最终阶段 V100：自适应阈值下 F1 **0.9916**、NG 召回率 **0.9833**、OK 特异度 **1.0000**，`FP=0, FN=2`。
- V100 使用 V10 固定阈值 0.66：F1 **0.9873**、NG 召回率 **0.9750**、OK 特异度 **1.0000**，`FP=0, FN=3`。
- 审计结果表明，每个阶段的历史 NG 训练重叠数均为 **0**。

这些结果说明当前模型可以在不回放历史 NG 的条件下继续学习，但阈值会随阶段明显漂移。自适应阈值能够掩盖部分分数标定变化，因此工业验收应同时查看固定阈值结果，并使用真实产线 OK 样本重新标定阈值。

## 2. 实验协议

### 2.1 模型和初始化

- 主流程：CPG-SSN（SuperSimpleNet 主干、位置归一原型、GLASS 风格特征扰动）。
- Backbone：ImageNet 预训练 ResNet-18，冻结特征提取器。
- 可训练参数：4,563,783。
- 输入：整图切成 256×256 图块，图像分数采用 Top-2 图块分数聚合，只输出 OK/NG。
- 每阶段训练 12 epochs，最多 2,000 个 tile/epoch；随机种子为 `20260910`。
- H01/V10 从基础初始化开始；其余阶段加载前一阶段可训练权重，增量阶段学习率缩放为 0.5。
- 未使用 S08 训练权重，避免其已接触全部六类缺陷而造成信息泄漏。

### 2.2 横向迭代

缺陷顺序为 `missing_hole → mouse_bite → open_circuit → short → spur → spurious_copper`。

- H01：基础权重 + 80 张 `missing_hole`。
- H02：H01 权重 + 80 张 `mouse_bite`，不训练 `missing_hole`。
- 后续阶段同理，每阶段只训练当前新类别的 80 张 NG。
- 测试集随已学类别扩展：20 张固定 OK + 每个已见缺陷类别 20 张 NG。

### 2.3 纵向迭代

- 每类 80 张训练 NG 按固定顺序切成 10 个互不重叠的数据块，每块每类 8 张，共 48 张 NG。
- V10 使用第 1–8 张，V20 只使用第 9–16 张，依次到 V100 只使用第 73–80 张。
- 各阶段继承上一阶段权重，但不再次训练之前的数据块。
- 所有阶段在固定的 20 张 OK + 120 张 NG 测试集上评估。

数据来源、SHA-256 摘要和重叠检查见 [no_replay_audit.json](iterative_no_replay/no_replay_audit.json)。完整阶段计划见 [plan_seed_20260910.json](iterative_no_replay/plan_seed_20260910.json)。

## 5. 错误样本与原因

V100 自适应阈值 0.5686 下的两张漏检均属于 `spur`：

- `ng:01_spur_16`，分数 0.5474；
- `ng:01_spur_17`，分数 0.5539。

固定阈值 0.66 下还会漏检 `ng:01_mouse_bite_16`（0.6338）。跨阶段反复靠近阈值的样本还包括 `open_circuit_12` 和 `open_circuit_17`。V80 自适应阈值产生的 4 个误检为 `ok:09_01`、`ok:09_07`、`ok:09_09` 和 `ok:10_02`。

主要问题不是模型完全丢失旧缺陷，而是严格无回放更新导致异常分数尺度漂移：六类排序能力仍强，但同一个固定阈值无法稳定覆盖所有阶段。`spur_16/17` 的异常区域弱、Top-2 聚合分数低，是当前最明确的漏检风险点。

推荐的下一轮工业优化：保留少量真实 OK 校准集并固定不参与训练；每次增量训练后只重新标定阈值，不访问历史 NG；验收时同时报告固定阈值和重标定阈值；针对 `spur` 弱缺陷增加更高分辨率或 Top-k/分位数聚合的消融。若业务允许极小历史缓存，可另外做每类 2–5 张难例回放对照，但应与本轮严格无回放结果分开报告。
