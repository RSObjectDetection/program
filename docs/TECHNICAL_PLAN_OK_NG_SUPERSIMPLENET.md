# 芯片整图 OK/NG 技术方案：CPG-SSN

## 1. 范围

当前阶段只判断整张芯片图像是 `OK` 还是 `NG`，不输出缺陷类别、缺陷框、掩码或偏移量。训练数据包括真实缺陷图及其图像级 NG 标签；正常图主要通过同型号芯片间的对齐和区域替换得到。

方案只采用一条模型主线：**以SuperSimpleNet弱监督流程为骨架的CPG-SSN（Component-Prototype Guided SuperSimpleNet）**。SuperSimpleNet原生支持正常图、仅图像级标注的异常图和不同监督强度，论文报告推理时间低于10 ms，并提供官方代码，符合当前数据和工业落地要求。

在完整SuperSimpleNet流程中只融合两个针对当前场景的模块：

1. 借鉴UniVAD（CVPR 2025）的部件感知匹配，在SuperSimpleNet已有特征上增加“同位置正常原型残差图”；
2. 借鉴GLASS（ECCV 2024）的近分布梯度异常合成，改造SuperSimpleNet训练期的随机特征扰动。

两个模块均复用SuperSimpleNet的同一个特征提取器：不增加DINO/CLIP等第二个大模型，不增加扩散模型，推理时仅增加一次轻量特征距离计算。

论文：<https://link.springer.com/article/10.1007/s10845-025-02680-8>

代码：<https://github.com/blaz-r/SuperSimpleNet>

UniVAD：<https://openaccess.thecvf.com/content/CVPR2025/html/Gu_UniVAD_A_Training-free_Unified_Model_for_Few-shot_Visual_Anomaly_Detection_CVPR_2025_paper.html>

GLASS：<https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/8382_ECCV_2024_paper.php>

## 2. 整体流程

```text
离线数据准备
真实NG图 ──配准──> 缺陷区域替换 ──质量检查──> 合成OK图
    │                                            │
    └────────────────┬───────────────────────────┘
                     ↓
            固定网格裁块/缺陷中心裁块
                     ↓
               CPG-SSN弱监督训练
                     ↓
在线推理
待测整图 → 配准与质量检查 → 固定网格裁块
                                      ↓
                       SuperSimpleNet共享特征F
                         ├─ 原分割/分类分支
                         └─ 同位置正常原型残差R
                                      ↓
                         融合[F, 内部异常图, R]
                                      ↓
                           Top-k图块分数聚合
                                      ↓
                                 OK 或 NG
```

与论文原流程相比，系统包含两个数据工程改动和两个模型内融合点：

1. 同型号芯片对齐后的正常图合成；
2. 高分辨率整图的固定网格裁块和图像级分数聚合。
3. UniVAD启发的同部件正常原型残差图；
4. GLASS启发的近分布特征异常生成。

SuperSimpleNet本身仍负责特征提取、内部异常图、分类头和最终异常分数；其主流程不变。其他论文只修改“参考差异”和“训练异常生成”两个明确接口。

## 3. 数据准备

### 3.1 数据划分

先按芯片模板、生产批次或连续拍摄序列划分 train/val/test，再做正常图合成。禁止先生成再随机划分，否则同一原图的内容可能同时进入训练和测试。

- 训练集：真实NG图和由训练图生成的OK图；
- 验证集：真实NG图和由验证图生成的合成OK图；
- 测试集：真实NG图和由测试图生成的合成OK图；
- 工业验收集：后续必须补充真实OK图，只在最终阶段使用。

合成验证/测试集只能用于研发比较，不能代表真实产线OK误报率。

### 3.2 图像配准

1. 选取一张结构完整、成像稳定的芯片作为模板。
2. 先用相位相关估计平移。
3. 再用ECC或稳定结构点估计仿射变换。
4. 所有图像映射到模板坐标系。
5. 记录ECC相关系数、重投影误差和有效区域比例。
6. 配准质量不达标的图像不参与正常合成；在线推理时返回图像无效而不是强制OK/NG。

### 3.3 合成正常图

当前数据已有VOC框时，框仅用于离线合成和裁块，不要求最终模型输出框。

对每张NG图：

1. 将缺陷框向外扩展10%–30%，覆盖可能存在的边界异常。
2. 在另一张已配准图的同坐标位置寻找供体区域。
3. 排除供体缺陷框与目标区域相交的图像。
4. 根据目标区域外围环带的颜色、梯度和SSIM选择最相似供体。
5. 对供体做局部颜色矩匹配。
6. 使用窄边缘alpha融合，避免硬拼接。
7. 替换后得到一张候选OK图。

每张候选OK图必须通过：

- 拼接边界梯度连续性；
- 替换区相对多个正常候选的一致性；
- 替换区外像素保持不变；
- 无其他标注缺陷；
- 人工抽检。

建议每张NG图最多保留1–2张高质量合成OK图，不追求大量低质量合成数据。

## 4. 高分辨率输入处理

原图约为3000×1500，直接缩放到256或512可能丢失小缺陷。第一版使用固定网格裁块：

- 图块大小：512×512；
- 重叠：64或128像素；
- 所有图像采用完全相同的模板坐标网格；
- 边缘不足部分使用反射填充；
- 在线将一张图的所有图块组成一个batch送入GPU。

训练样本构造：

- 合成OK图的所有图块标为OK；
- 原始NG图中与缺陷框相交的图块标为NG；
- 原始NG图中距离缺陷框足够远的图块可作为真实局部OK，但第一轮实验先不使用，避免漏标污染；
- 每个epoch对OK/NG图块做均衡采样。

如果后续数据只有整图标签、没有框，则改用整图级多实例训练；这不是当前第一版范围。

## 5. CPG-SSN模型与训练

### 5.1 SuperSimpleNet主流程

SuperSimpleNet首先用预训练卷积网络提取多层特征，放大并融合中间层特征；训练时在潜空间中用Perlin掩码限制高斯扰动，生成空间连续的合成异常特征。分割头生成内部异常图，分类头将异常图和特征结合，输出图像级异常分数。推理时潜空间异常生成模块被移除，只保留特征提取和判别网络。

虽然业务不输出掩码，内部异常图仍然保留，因为它是SuperSimpleNet分类头的一部分，并能帮助模型关注小缺陷。

### 5.2 融合模块一：部件约束正常原型残差

UniVAD通过部件感知匹配减少不同结构区域之间的错误对应。当前芯片型号一致且图像已配准，因此将其简化为工业上更直接的“固定位置正常原型”。

离线阶段，对每个固定网格位置 `g`，使用合成OK图通过SuperSimpleNet特征提取器得到特征，并计算稳健正常原型：

```text
P_g = median({F_ok,g})
```

推理时复用同一个SuperSimpleNet特征 `F_x,g`，计算余弦残差：

```text
R_g = 1 - cosine(F_x,g, P_g)
```

将残差图经过一个 `1×1 Conv` 压缩后，与SuperSimpleNet原分类头已有的特征和内部异常图拼接：

```text
score = D_cls([F, M_pred, Conv1x1(R)])
```

这不是额外的异常检测器。正常原型提前离线计算并缓存；在线只增加逐位置余弦距离和一个1×1卷积。它直接利用“芯片结构相同、正常位置可对齐”的业务先验，也能帮助发现偏移、缺失和局部污染。

### 5.3 融合模块二：GLASS式近分布特征扰动

原始SuperSimpleNet在Perlin掩码内加入随机高斯噪声。该方式覆盖面广，但容易生成与真实轻微划痕或弱污染差别较大的特征。

CPG-SSN保留Perlin空间掩码，但训练批次中的潜空间异常分为两类：

- 50%使用SuperSimpleNet原始高斯扰动，保持异常多样性；
- 50%借鉴GLASS的Global Anomaly Synthesis，在分类边界方向做有限步梯度上升，并进行范数截断，使异常特征靠近正常分布边界。

简化实现为：

```text
epsilon_0 ~ N(0, sigma²)
epsilon_(t+1) = Project(epsilon_t + eta * grad_epsilon L_normal)
F_anom = F + PerlinMask * epsilon_T
```

只执行1–3步梯度更新，`Project`限制扰动范数。该模块只存在于训练阶段，在线推理完全移除，因此不会增加部署延迟。这里不引入GLASS完整网络，只借用其“生成靠近正常边界的弱异常”机制替换一半随机扰动。

### 5.4 监督方式

采用论文的弱监督方式：

- 合成OK图块：图像标签 `0`；
- 真实缺陷图块：图像标签 `1`；
- 真实缺陷不使用矩形框作为像素级掩码，避免粗框把大量正常背景标成异常；
- 潜空间合成异常拥有准确的Perlin掩码，用于训练内部异常图分支。

这比此前“框直接转换为粗掩码”的方案更符合真实监督信息。

### 5.5 骨干选择

第一轮先使用论文官方WideResNet50配置，确保验证主方法本身。确认有效后，再比较ResNet18轻量版本。

不建议一开始直接使用ResNet18，因为之前的适配实验同时存在伪正常图块、粗掩码和低分辨率问题，无法判断性能下降究竟来自骨干还是数据构造。

### 5.6 训练设置

- 输入：512×512；
- 优化器和学习率先采用官方配置；
- 分类损失：论文原有focal loss；
- OK/NG batch尽量保持1:1；
- 早停指标：验证集图像级AUPRC，其次AUROC；
- 每个实验运行3个随机种子；
- 保存best checkpoint、训练曲线、阈值和数据清单哈希。

## 6. 整图分数聚合

SuperSimpleNet输出每个图块的异常分数 `s_t`。由于重叠网格会使同一缺陷出现在相邻图块，整图分数采用Top-2均值：

```text
S_image = mean(two largest tile scores)
```

同时保留以下聚合作为消融：

- 最大值：召回高，但容易被单个噪声图块触发；
- Top-2均值：默认方案；
- Top-3均值：较稳定，但极小缺陷可能被稀释。

阈值必须对聚合后的整图分数进行标定，不能直接沿用单图块阈值。

## 7. 在线决策

```text
若图像读取、曝光、清晰度或配准失败 -> INVALID_IMAGE
否则若 S_image >= T_ng              -> NG
否则                                 -> OK
```

验证集上先确定满足目标NG召回率的阈值，再测量OK误报率。工业场景通常应优先降低漏检，因此阈值选择建议以“NG召回率至少达到指定值”为约束，而不是单纯选择最高F1。

## 8. 实验计划

| ID | 配置 | 目的 |
|---|---|---|
| S00 | 现有ResNet18伪正常图块基线 | 保留历史结果 |
| S01 | 官方SuperSimpleNet + 新合成OK图 + 512图块 | 主干基线 |
| S02 | S01 + UniVAD式正常原型残差 | 验证参考残差模块 |
| S03 | S01 + GLASS式近分布扰动 | 验证异常生成模块 |
| S04 | S01 + 两个模块，即完整CPG-SSN | 最终主模型候选 |
| S05 | S04，比较max/Top-2/Top-3聚合 | 选择整图聚合方法 |
| S06 | S04，图块重叠64与128像素 | 验证边界缺陷召回 |
| S07 | S04，30/50/100张NG图每类 | 数据量曲线；仍只做OK/NG |
| S08 | S04改为ResNet18 | 轻量化损失评估 |
| S09 | 最佳模型在真实OK图上校准 | 工业验收前必做 |

S01–S04构成严格消融，可以分别证明两个论文模块是否真正改善当前数据，而不是一次加入后无法解释收益来源。

## 9. 指标

主要报告整图级指标：

- NG Recall及漏检率；
- OK Recall及误报率；
- Precision、F1、Balanced Accuracy；
- AUROC和AUPRC；
- 每种缺陷分别计算NG Recall，虽然暂时不输出类别；
- batch=1整图P50/P95延迟；
- 显存峰值和模型大小；
- `INVALID_IMAGE`比例。

论文中的像素级指标不作为本项目主要指标。

## 10. 当前决策

1. 主方法确定为以SuperSimpleNet弱监督流程为骨架的CPG-SSN。
2. 正常原型残差模块借鉴UniVAD，但复用SuperSimpleNet特征，不运行第二个基础模型。
3. 训练异常生成模块混合SuperSimpleNet原始扰动与GLASS式近分布梯度扰动。
4. 不使用YOLO、DINO、CLIP、元学习或扩散模型。
5. 真实NG样本全部合并成一个NG类。
6. 正常图通过配准后的同坐标区域替换生成。
7. VOC框仅用于合成正常图和选择NG图块，不作为模型输出，也不转换为真实像素掩码。
8. 高分辨率图通过固定网格处理，整图采用Top-2图块分数聚合。
9. 多类缺陷识别推迟到OK/NG达到稳定效果之后。
